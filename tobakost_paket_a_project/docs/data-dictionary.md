# Data Dictionary

Versi awal data dictionary berada pada pipeline ETL dan view `vw_mart_kos_lengkap`.
Dokumen ini harus dilengkapi dengan nama kolom, definisi bisnis, tipe data, satuan, sumber,
aturan validasi, dan apakah kolom digunakan sebagai fitur model.

Setiap perubahan schema wajib menaikkan versi data dictionary dan dicatat pada laporan mingguan.
