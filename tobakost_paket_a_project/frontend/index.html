Sumber Data Latih: 600 baris data primer survei Google Form kos Kabupaten Toba (480 Train / 120 Test) dari SQLite Star Schema Data Warehouse.

Target Prediksi (Y): Tarif sewa kos bulanan ekuivalen (harga_bulanan_norm dalam Rupiah/bulan).

Performa terbaik berdasarkan MAE test set: menunggu metrik dari bundle model.

Runtime model: menunggu status backend.

Batasan Penggunaan: Model dikalibrasi khusus untuk karakteristik pasar kos di Kabupaten Toba dan tidak ditujukan untuk kota metropolitan di luar Toba tanpa pelatihan ulang.
